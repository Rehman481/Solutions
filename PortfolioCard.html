✧ CSS Reflection

Box-shadow felt confusing at first because adjusting blur and spread values seemed unpredictable — I resolved it by testing each value individually (offset-x, offset-y, blur, spread, color) to understand their impact on depth perception. Margin collapsing between the header and section also caused spacing issues, which I fixed by using padding on the parent card container and gap in flex layouts instead of relying solely on margins. Border-radius combined with borders and backgrounds required experimentation with different values and using overflow: hidden where needed to achieve the smooth, polished look I wanted. I also found font pairing tricky — Merriweather for headings and Inter for body text gave the right balance of elegance and readability without sacrificing performance.
